# Project conventions

## Git attribution — no AI attribution, ever

When committing, opening a pull request, or pushing changes in this repository:

- Do **not** add `Co-Authored-By: Claude ...` or any other AI co-author trailer to commit messages.
- Do **not** add "Generated with Claude Code", robot emoji footers, or any similar line to commit messages or pull request descriptions.
- Do **not** set an AI tool as the commit author or committer. Commits are authored by the repository owner only.

This applies to every commit, amend, squash, merge commit, tag message and PR body, with no exception and without needing to be asked again.
